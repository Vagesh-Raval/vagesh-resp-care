# Vagesh Raval Portfolio

## Goal
Build a cinematic, single-page professional portfolio that presents Vagesh Raval’s verified biomedical engineering experience, respiratory and critical-care specialization, education, and BreatheAssist work without adding unverified claims.

## Experience
- Create a fixed, smooth-scrolling navigation with clear section links and a compact mobile menu.
- Open with the uploaded BreatheAssist film as a full-width, muted, looping background, with the requested headline and two direct actions.
- Establish a premium technical visual language using near-black, graphite, off-white, cyan, and ice-blue accents; precise typography; subtle grid/detail lines; and restrained motion.
- Build all requested sections: About, five healthcare departments, diagnosis-to-therapy comparison, respiratory specialization, featured BreatheAssist project, six-step workflow, professional timeline, skills, education, journey, and contact.
- Add purposeful interactions: department selector, diagnosis/therapy switch, workflow progression, skill filters, video controls, mobile navigation, and a CV preview/download dialog.
- Use the supplied PDF as the downloadable CV and the supplied MP4 in both the opening and flagship project presentation.

## Content Integrity
- Use only facts present in the uploaded profile and the verified brief.
- Treat the supplied ventilator footage as a concept visualization, not a claim that it depicts a production device.
- Describe department equipment at category level where the source does not name specific devices.
- Link both verified email addresses and the verified LinkedIn profile; do not add phone numbers, certifications, employers, awards, or metrics.
